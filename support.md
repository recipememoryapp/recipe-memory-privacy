# Recipe Memory Support

Thanks for using Recipe Memory!

Recipe Memory is a personal recipe organization app designed to help you save, organize, and revisit recipes you discover online.

## Need Help?

If you're experiencing a problem with Recipe Memory, have a question, or would like to provide feedback, please contact:

**Email:** recipememoryapp@gmail.com

When reporting a problem, it may be helpful to include:
- A brief description of what happened
- The type of device you're using
- Any steps that caused the problem

Please do not include passwords or other sensitive information.

## Common Questions

### How do I save a recipe?
Use the Add tab in Recipe Memory to enter a recipe link and save it to your personal library.

### Can I organize my recipes?
Yes. Recipe Memory lets you organize saved recipes into collections so they're easier to find later.

### Can I view the original recipe?
When a source link is available, Recipe Memory keeps the original recipe source attached to your saved recipe.

### Is my recipe library private?
Recipe Memory is designed as a personal recipe library associated with your account.
